## Profile 分兩層

- **簡介** — Hinge 嗰邊。固定幾件 element（相／歌／問答／一句話／睇緊），係「我係邊個」。每件獨立可以 ♡ — 你 like 嘅係嗰件嘢，唔係成個人。
- **貼文** — IG 嗰邊。無限咁 post，累積成 grid，最新喺前，係「我最近做緊乜」。

兩層性質唔同，所以分開。Hinge 得前者，IG 得後者。

## 入會

唔使自拍。讀一句隨機而且中性嘅句子就得 —— 當住屋企人面前讀都唔會出事。
AI 只負責放行，唔確定嘅落人手，**永不自動拒絕**。同一段錄音順便標返你講粵／英／普。
