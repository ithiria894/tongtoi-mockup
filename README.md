## Profile：一條 scroll，冇 tab

上面係**簡介**（Hinge 嗰邊）：固定幾件 element — 相／歌／問答／一句話／睇緊。係「我係邊個」，好耐先改一次。每件獨立可以 ♡ — 你 like 嘅係嗰件嘢，唔係成個人。

捲落去係**貼文**（IG 嗰邊）：無限咁 post，grid 一路長，最新喺前，係「我最近做緊乜」。

⚠️ **試過分兩個 tab，拆咗。** 分咗 tab 冇人會撳入第二格，而 IG 自己都係一條 scroll（bio → highlights → grid）。次序啱就夠。

## 開枱係物件，唔係地方

群就係 **WhatsApp／TG 嗰種**，唔使發明新玩法。開枱只不過係你可以喺入面掟一張卡出嚟，好似掟個 location 或者 poll。

但張枱本身係一個**物件**：時間、地點、上限、報名名單全部跟住佢走。所以佢可以同時出現喺群同討論區 — **唔係兩套開枱，係同一張枱出現喺兩個地方**，一份名單。

可見度跟住你貼喺邊：貼落私密群 → 淨係群友入到；貼落討論區 → 成個城市見到。
