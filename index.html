今日發明過然後拆咗嘅：麻雀枱視覺 · 群命名規則 · 私聊開枱 · 自己諗嗰套「3+／10+／50+ 回覆」filter（冇人咁做）。
Discourse 個 Unanswered 啱啱好就係救「新人死亡螺旋」嗰條 — 業界早有答案，唔使發明。

⭐ 我哋畀機制，唔畀用途

我哋起嘅係機制：post／thread · 群 · 開枱卡 · profile · filter · 語音門檻。 點用係用戶嘅事。

分辨方法：約束我哋自己嘅規矩（唔可以加咩）✅ 合法； 約束用戶點用嘅規矩（佢應該點改名、應該點玩）⚠️ 通常係諗多咗。

今日拆咗兩條：群要圍繞一件事、唔開全城大群 — 兩條都係管用戶。 留低嘅（作曲框一個輸入位、空台唔好開、AI 只放行）全部係管我哋自己。

如果個個都躲喺群唔出 Thread — 嗰個係數據，話畀我哋知 Thread 做得唔夠好， 唔係用戶做錯。

出 post 只係打字

Threads 贏喺打一句就出得，唔使用腦。所以個作曲框唔可以排欄位畀人揀 — 就算全部 optional，一樣佔視線、一樣要人決定。

⛔ 硬規矩：作曲框永遠只有一個輸入位。 三粒 chip 今日冇嘢， 但呢個位冇上限 — 聽日加「心情」就四粒，再加「只限已驗證」就五粒。 新嘅 metadata 維度只可以推斷或者出咗之後改。 唔係靠自律，係根本冇位擺第四粒。

城市／語言係「人」嘅屬性

「瞓唔著」關溫哥華咩事？ 冇。硬塞個城市落每個 post， 篩「溫哥華」就會撈返一堆無關嘅嘢 — 個 filter 就廢咗。

阿霖住溫東，寫喺佢 profile；註冊嗰段錄音已經標咗佢講粵語。 所以篩「溫哥華」＝篩「作者住溫哥華」，永遠準。

post 可以完全冇話題、冇 tag — 呢個係常態。冇建議就連 toast 都唔出。

唔叫「討論區」，叫「Thread」

個名會落框。叫「討論區」，人一睇就以為要好似連登咁開正經 post — 想嗌一句「我想要老婆啊」嘅人會覺得自己唔啱格式，然後唔出。

所以 label 唔可以規定格式。其他人選：講嘢 · 而家。

論壇性係長出嚟，唔係揀出嚟

論壇獨有嘅只有三樣：分台瀏覽 · 舊 post 搵得返 · 有標題可以掃， 而三樣都要有量先有意義。Butterfly 就係論壇形態，佢死緊。

所以：人人只係出 post；儲到討論就自己變成一條 thread。 排序用最後回覆頂上去（連登嗰套）— 冇人回就沉，有人回就浮， 唔使演算法都篩到料。

唔用台，用標籤 · 分三層

台係「有／冇」，標籤係「多／少」。 空台係一個望到嘅洞； 少人用嘅標籤只係唔浮出嚟。同樣得幾百人 — 一個顯得死，一個顯得正常。

但自由標籤會散（多倫多／Toronto／多倫多多倫多）。所以分三層：

① 人嘅屬性（城市·語言）— 喺 profile，唔喺 post
② 策展話題（出櫃·落地·感情）— 自動建議 ＋ 同義詞歸邊
③ 自由 tag（#行山 #打邊爐）— 隨便打，散咗都唔緊要， 因為冇人靠佢瀏覽

論壇性 = 三條 filter：話題 ＋ 回覆 ≥ N ＋ 全部時間。 三條加埋 = 一個台，而且你可以存低做自己嘅台。

一句 ＋ 長 post，一條 feed

唔開第二個 tab，視覺上分得出就夠。但唔做無限捲 — thesis 話 swipe 係老虎機，無限隨機 feed 係同一機制。

無限 ＋ 演算法 = 老虎機。有限 ＋ 有序 = 告示板。 差別唔喺 UI，喺有冇盡頭。捲到底會見到「你追返晒喇」。

兩個「樹」都唔要：板塊樹用標籤取代；回覆樹用平鋪 ＋ 引用 （連登去到 1001 回覆都係平鋪）。結構係要用量嚟養嘅。

⭐ 兩個入口分開：公海只有公開覆

Hinge 冇公開 like、冇公開 reply — 所以喺嗰度「like／reply」 一定係私下示好，唔可能誤會。我哋兩樣都有，所以唔可以喺同一個位擺兩個掣， 靠 label 分。

⭐ 用結構分，唔靠 label：
· Thread 同討論串 — 淨係公開覆，冇私下入口
· 想私下搵佢 — 撳佢個頭像入 profile，喺度搵返嗰句／嗰張相， 就嗰件嘢搵佢

睇你喺邊度，就知你做緊邊樣。 冇得誤會。

點解唔喺 Thread 畀個捷徑：防 spam。 一撳就出手，成個 feed 會變晒騷擾。 入口喺 profile，你要撳入去、見過佢係咩人先搵得到佢。

⚠️ 但摩擦擋唔到有心人。由 feed 撳頭像會直接跳到嗰句（唔使你自己捐返出嚟）， 即係兩撳搞掂 — 真心想 spam 嘅人唔會介意。

⭐ 所以真正防 spam 嘅係配額，而呢個係業界標準： Hinge 免費版每日 8 個 like · Bumble／Tinder 都有每日上限。 全部用配額，唔用摩擦 — 因為摩擦只會煩親正常人。

兩樣一齊：入口喺 profile（擋衝動、逼你睇過個人）＋ 每日配額（擋真 spam）。
而配額淨係計私下搵人。公開覆人（Thread／討論串）冇上限 — 嗰度係 Twitter。

💰 收錢就收喺呢一格，唔收第二度。 Hinge 8 like／日、Tinder Super Like、 Bumble Extended — 全部揀咗同一格，唔係巧合：呢度係唯一一個 「用戶真心想要多啲」而畀咗又唔會整污糟其他人體驗嘅位。
唔賣「邊個 like 咗你」（賣返你自己嘅嘢畀你）、唔賣 boost（賣其他人嘅注意力）。

⚠️ 唔好假設佢個動機。 人撳你個頭像可能純粹好奇、因為個 icon、因為個名 — 唔一定係因為嗰句。夾硬彈句嘢叫佢「就呢句搵佢」，會迫出「哈哈哈」呢種無意義回應， 而 context 本來係我哋最大優勢，變咗假嘅反而更差。

所以頂上嗰行寫「你頭先睇嗰句」— 一個事實，唔係一個推測。 細行、灰色、細 link，明顯係捷徑唔係指示。下面成個 profile 照樣喺度。

私下嗰個唔係齋 DM：帶住你就邊件嘢搵佢，而且要佢覆返先開到對話 — 唔覆＝乜都冇發生過，你個 inbox 唔會多咗個陌生人。

公開／私底下 — 抄 Twitter 個軸，抄 Hinge 個做法

每一件嘢都有兩個做法：💬 覆（公開，大家見到）· ♡ 撩（私底下，只有佢見到）。

呢個唔係新嘢 — Twitter：Reply／DM · IG：Comment／DM · Reddit：Reply／PM。 用戶一世都喺度分緊「公開講」同「單獨傾」，唔使學新概念。

⚠️ 但呢個「私訊」唔係齋 DM。 Twitter／IG／Reddit 個 DM 係一個空白框 — 你自己諗點解釋「我搵你做乜」。Hinge 唔同：

· 開場已經有 context — 就邊件嘢搵佢 ＋ 你講咗咩
· 對方見到嘅唔係陌生人，係「佢因為我嗰句先嚟」
· ⭐ 要佢覆返先開到對話 — 齋 DM 係直接入 inbox，呢個係一個請求

最後嗰點最緊要：冇覆 → 個對話根本冇開過，你個 inbox 唔會多咗個陌生人。 呢個亦都係「安靜拒絕」嘅由來。

所以準確講：公開／私底下呢個軸抄 Twitter；私底下嗰邊點運作，抄 Hinge。

而且私訊入口喺內容出現嘅每一個地方都有 — Thread、討論串、profile、相內頁。 唔止喺 profile 先有。

⭐ 私訊嘅入口唔限於策展內容

Hinge 嘅限制：佢啲 element 係固定款式（6 張相 ＋ 3 條 prompt）。 因為 Hinge 冇社群內容 — 佢冇嘢可以畀你做入口。

我哋有。 佢喺呢度產生過嘅任何嘢都做得入口： 簡介 element · 相 · 出過嘅 post · 講過嘅一句 · 覆過人嘅嘢。

⭐ 最後嗰樣先係最強：
策展嘅 prompt 係佢想你睇到嘅自己。
討論串入面嗰句回覆係佢冇防備嗰陣點對人。
後者係更好嘅證據 — 而且啱返個 thesis：你識人係經過內容，唔係經過 profile。

而且呢個令 profile 唔使「填」— 你喺 Thread 講過嘢，你個 profile 就自動有嘢畀人做入口。

💥 Hinge 數字：就 prompt 私訊，勝過就相 47%

Hinge 標準：6 張相／片 ＋ 3 條 prompt（題庫 105+ 條分 10 類）， 撳心喺單一張相／單一條 prompt／單一段語音上面，可以附一句 comment， 去對方個 Likes You queue。

💥 而 Hinge 自己嘅數據：就「prompt」私訊比就「相」私訊，成功約到會嘅機率高 47%。 即係就一件文字嘢入手，贏過就一張臉入手 — 直接驗證咗我哋成個 element 設計。

所以 prompt 題庫要寫得好、分夠類 — 佢係 profile 嘅靈魂，唔係附加品。

唔抄嘅：Roses（付費插隊 — 細社群唔應該有人用錢插隊）、 Standouts（會變成人氣榜）。

Grid 係相簿，唔係 feed

好多人用 IG 唔係成日出 post — 佢一世得八個十個 post， 就係話畀人聽自己係咩人。

所以 grid 唔係一條 feed，係一個自我介紹。設計上即係：

· 唔為「經常出 post」而設計
· 得幾張相係正常，唔係「未填好」 — 冇「完成度 60%」呢類催促
· 「擺兩三張似 Hinge」係常態唔係例外

⚠️ 冇 Close Friends。 IG 嗰個機制預設有 friend graph， 我哋冇 — 抄嗰陣淨係睇機制冇睇前提。而且更根本： 個 profile 係展示自己，唔係 share 畀 friend， 佢本來就係畀任何撳入嚟嘅人睇，有分層先係矛盾。

剩返兩層就夠：出 Thread（成城見到）· ◔ 淨係 profile（撳入嚟先見到）。

Profile：一條 scroll，冇 tab

簡介（Hinge）：固定幾件 element — 歌／問答／一句話／睇緊。 每件獨立可以 ♡ — 你回應嘅係嗰件嘢唔係成個人，開場白自動有咗。

講過嘅嘢（Threads／FB）：自己出過嘅一句。
post（IG）：無限 grid，最新喺前。

試過分 tab，拆咗 — 冇人會撳入第二格，而 IG 自己都係一條 scroll。 相只有一個家，形態由用戶自己用出嚟：擺兩三張似 Hinge， 擺幾十張似 IG。冇 mode、冇設定。

Match ＝ 佢覆咗你，唔係一個抽獎結果

流程：喺搵人度掃 → 撳 ✉ 就佢其中一件嘢私訊 → 佢見到你係就邊件嘢搵佢 ＋ 你講咗咩 → 佢覆返，私聊自動開。

冇「MATCH!」煙花，因為唔使。 個對話一開就已經有內容（你撩咗邊件嘢、佢覆咗咩）， 開場白天生就有 — 呢個正正係 Hinge 贏 Tinder 嗰點。

Tinder 個 match 係抽獎結果：兩個人互相 yes 咗一張臉，然後對住空白框 諗「講咩好」。我哋個 match 係一次對話嘅第二句。

⭐ 唔覆＝乜都唔會發生。 冇人知你睇過，佢個 like 就咁靜靜哋收埋 — 拒絕唔使講出口。呢樣對未出櫃嗰批好重要。

Profile 係堵「加你 IG 睇下」個窿

而家其他 app 個流程：識到 → 交換 IG → 走去 IG 睇佢咩人 → 之後就喺 IG 傾。

一交換 IG，關係就離開咗個平台。 對大廠係流失；對我哋啲用戶更慘 — 你要交出真名、熟人圈、成個社交足跡，先驗證到你係咩人。未出櫃嗰批交唔起。

所以個 IG 層唔係加多個功能，係堵返個窿：想睇佢咩人 → 就喺呢度睇，代價零， 之後照樣留喺度傾。

呢個解釋埋點解個 profile 要厚（相 ＋ element ＋ 講過嘅嘢）— 因為佢要做到真 IG 做嘅事：畀人 scroll 五分鐘，大概知你係咩人。

❌ 冇 follower 數

呢個係交友 app，唔係 KOL app。 個 profile 係畀人了解你，唔係畀人評分你 — 一有公開數字，兩件事就對調。

而且我哋根本冇 follow — Thread 係成個城市，唔使 follow 任何人就見到晒。 冇 follow graph，就冇嘢好數。

一有公開數字，人就會對住觀眾表演，唔係對住一個可能會見面嘅人講嘢。 而未出櫃嗰批（唔貼相、唔用真名、唔想曝光）喺呢個計分板上面永遠輸， 變咗二等公民 — 直接踩死我哋最想服務嗰批人。

回訪：靠「有人覆你」，唔靠演算法

我哋規模下最強嘅回訪動力唔係 feed 調校 — 幾千人，內容就係得咁多，點排都係嗰啲。 最強嗰樣係 「有人覆咗你」，而呢樣大廠反而做唔到 （幾億人，你條 post 沉咗就係沉咗）。

通知全部係真嘢：有人覆你 · 有人就你其中一件 element 私訊你 · 有人報咗你張枱 · 有人睇過你 profile。冇一條係「你可能會鍾意…」。

⚠️ 排序唔可以淨係按熱度。 純 bump 排有個死症： 新人第一篇冇人覆 → 永遠沉底 → 冇人覆 → 佢走。新人死亡螺旋。 要溝埋「你未見過嘅嘢」加分。細節待定，方向係好似 Twitter／FB／Threads 咁。

唯一底線：排序要講得出係點排，唔係黑箱。

群 = WhatsApp／TG 嗰種，唔發明新玩法

冇群，啲人就走去 TG，然後成班消失 — 呢個喺 Butterfly 親眼見到 （佢哋喺討論區出帖叫人入 Telegram 群）。所以群一定要有。

群主自己改個名，改咩都得 — 「30+ 吹水」「行山 group」「夜晚鳩噏 group」， 全部合法。唔規定人哋點命名。

Thread＝對住成個城市講嘢（識新人）；群＝對住已經識嘅人講嘢（留得低）。 平台唔會主動開一個官方全城群（呢個係我哋嘅克制）， 但用戶想開咩就開咩（呢個係佢哋嘅自由）。

如果大家真係自己聚埋開咗個大群 — 咁係個訊號話畀我哋知 Thread 做得唔夠好，唔係佢哋做錯。

而且群開嘅枱可以貼返上 Thread — 群變成 Thread 嘅內容來源，唔係抽水位。

開枱係物件，唔係地方

群就係 WhatsApp／TG 嗰種，唔發明新玩法。開枱只係喺入面掟一張卡， 好似掟個 location 或者 poll。

⚠️ 開枱係多人機制，唔關私聊事。 兩個人喺私聊講「聽日食宵夜？」使乜咁大陣象 — 加個 RSVP 卡落一對一對話係典型嘅過度設計。兩條路分開：
· 一對一：搵人 → 私訊 → 佢覆 → 對話 → 自己講就得
· 多人：群／Thread → 開枱（有名額、有名單）

但張枱係一個物件：時間、地點、上限、報名名單跟住佢走。 所以佢可以同時出現喺群同 Thread — 唔係兩套開枱，係同一張枱兩個地方，一份名單。 （喺 Thread 報名，入返個群睇，個數會一齊變。）

註冊 ＋ 假面

註冊：唔使自拍。讀一句隨機而且中性嘅句子 — 當住屋企人面前讀都唔會出事。AI 只負責放行，唔確定嘅落人手， 永不自動拒絕。

⛔ 語音淨係做一件事：分男女。 本來寫住「同一段錄音順便標返你講粵／英／普」—— 斃咗（Nicole 2026-08-16）。兩個理由：查證發現冇一個現成模型又分到粵普又准商用； 而且個 app 將來要開放畀更多語言嘅人用，寫死粵／普／英本身就係錯方向。 語言改成用戶自己揀，可多選，任何語言加得。

假面：搖一搖變成真係用得嘅計數機，撳返一段特定數字先返到去。 對「同屋企人住、阿媽會攞我電話」嘅人，唔係花巧，係用唔用得落去嘅分別。
