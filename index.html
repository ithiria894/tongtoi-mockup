PROFILE：一條 SCROLL，冇 TAB

上面係 簡介（Hinge 嗰邊）：固定幾件 element —— 相／歌／問答／一句話／睇緊。 係「我係邊個」，好耐先改一次。每件獨立可以 ♡ —— 你 like 嘅係嗰件嘢唔係成個人， 所以開場白自動有咗。

捲落去係 貼文（IG 嗰邊）：無限咁 post，grid 一路長，最新喺前， 係「我最近做緊乜」。撳入去有 caption 同回應。

試過分兩個 tab，拆咗。 分咗 tab 冇人會撳入第二格 —— 而 IG 自己都係一條 scroll（bio → highlights → grid）。次序啱就夠： 「我係邊個」喺前，「我最近做緊乜」喺後。

相只有一個家，就係下面個 grid。形態由用戶自己用出嚟： 擺兩三張 → 睇落似 Hinge；擺幾十張 → 似 Hinge 加 IG grid。 同一個介面，冇 mode、冇設定、冇嘢要學。

一種嘢，兩個欄位，三個鏡頭

連登點解 work：內容歸「台」，唔歸「人」。你入感情台係因為想睇感情嘢， 唔係因為想睇邊個。連登人唔 follow 人。
Threads／FB 啱啱相反：內容歸「人」，累積喺 profile。

兩個係相反嘅歸檔方式 — 所以唔好當佢係兩個產品。 每篇嘢都有「作者」同「台」兩個欄位，之後三個鏡頭睇同一堆嘢：

· 篩個台 → 連登
· 篩個作者（＝ profile）→ Threads／FB
· 唔篩、時序排 → Twitter

長帖同一句嘅唯一分別係有冇標題：有標題 → 有回覆樹（連登款）； 冇標題 → 一句（Threads 款）。兩者都歸台、都歸人。

⚠️ 真正代價唔係複雜度，係空。 50 個用戶開 8 個台 = 個個台三兩條，似死城， 仲衰過冇分台。所以資料模型全部有，介面夠人先出現 — 上面兩個 🔒 就係未夠量嘅台。

點解唔叫「討論區」

個名本身就會落框。 叫「討論區」，人一睇就以為要好似連登咁開個正經帖 — 想嗌一句「我想要老婆啊」嘅人會覺得自己唔啱格式，然後唔出。

所以個 label 唔可以規定格式。而家用緊 大廳 — 一間房，大家喺度，冇話你要講咩點講。其他人選：講嘢（鳩up 係講嘢，討論都係講嘢）、 而家（乾、接返「未瞓」）。一句就換得。

唔使分兩個入口 — 分嘅位喺個作曲欄，唔喺個 tab。 而且「✎ 寫一句」要做主角（高亮嗰個），「＋ 開個帖」做次要： 低門檻嗰個先應該最搶眼。

兩個「樹」都唔要

板塊樹（台 → 子台 → 帖）：十個板塊每個得一兩條，衰過唔分。用標籤取代。

回覆樹（嵌套回覆，Reddit 嗰種）：要一條帖幾百個回覆、分開幾條支線先有意義。 我哋一條帖得五至四十個回覆 — 嵌套只係加視覺複雜度，換唔到嘢。
連登係平鋪嘅，去到 1001 個回覆都仲係一條直線，靠引用接返上文。 呢個做法喺極大量都撐得住。

⭐ 結構係要用量嚟養嘅。 台要有帖先唔空、嵌套要有支線先有用、 板塊樹要有流量先分得開。人少嗰陣，平鋪 ＋ filter 每次都贏 — 而 filter 唔使量養，一個人都用得。

唔用台，用標籤

台係「有／冇」，標籤係「多／少」。 一個空台係一個望到嘅洞； 一個少人用嘅標籤只係唔浮出嚟。同樣得幾百人 — 一個顯得死，一個顯得正常。

Butterfly 就係台嗰個形態（佢個描述寫住「免費討論區」分 lesbian life／love／ LGBTQ／性向／興趣）。而佢而家 2.7 星、兩年冇更新。

但自由標籤會散晒（出櫃／出柜／comingout 分四邊，然後樣樣都冇人）。所以： ① 建議標籤，唔係自由填；② 條標籤列按活躍度排 — 死咗嘅自己沉走，唔使人手清。冇人用嘅標籤自動消失，所以永遠唔會有空台。

論壇性係長出嚟嘅，唔係揀出嚟嘅

論壇形式（連登、Butterfly）獨有嘅只有三樣：分台瀏覽 · 舊帖搵得返 · 有標題可以掃。 而呢三樣全部要有量先有意義。

論壇要人多先活得成 — Butterfly 就係論壇形式，佢死緊。 微博形式喺人少嗰陣照樣成立：一條 post 得四個回覆都仲似有人。 我哋開頭得幾百人，論壇形態喺呢個量級係必死嘅。

但唔一刀切掉論壇。 人人只係出 post；有 post 儲到討論， 佢自己就變成一條 thread — 有 permalink、搵得返、不停 bump。 論壇性係一條有人回嘅 post 長出嚟嘅結果，唔係一個要揀嘅模式。

所以個作曲欄係一個框。標題同台係可選（想加先加）， 唔係出手前嘅關卡 — 逼人宣告「我而家出緊認真帖」本身就係 friction。

排序：最後回覆頂上去（連登嗰套）。 冇人回就沉，有人回就浮。 唔使演算法都自動篩到料。
⚠️ 呢個更新咗 thesis 入面「時序排」— bump 唔係創建時序，但一樣冇演算法、 有盡頭、人人睇得明。

一句 ＋ 長帖，一條 FEED

討論區溝埋兩種嘢：長帖（有標題、有回覆樹，似連登）同一句（似 Twitter， 半夜擺個諗法出嚟）。唔開第二個 tab —— 視覺上分得出就夠。

但唔會做成無限捲。 我哋自己份 thesis 話 swipe 係老虎機； 無限隨機 feed 係同一個機制換咗文字。所以：時序排、會捲到底。 捲到最後有一句「你追返晒喇」—— 呢個係 feature。

而且淨係你個城市，幾千人，個個你真係撞得到。 咁就唔係老虎機，係細鎮嘅告示板。

開枱係物件，唔係地方

群就係 WhatsApp／TG 嗰種，唔使發明新玩法。開枱只不過係你可以喺入面掟一張卡出嚟， 好似掟個 location 或者 poll。

但張枱本身係一個物件：時間、地點、上限、報名名單全部跟住佢走。 所以佢可以同時出現喺群同討論區 —— 唔係兩套開枱，係同一張枱出現喺兩個地方， 一份名單。（試下喺討論區報名，入返個群睇，個數會一齊變。）

可見度跟住你貼喺邊：貼落私密群 → 淨係群友入到；貼落討論區 → 成個城市見到。

入會

唔使自拍。讀一句隨機而且中性嘅句子 —— 當住屋企人面前讀都唔會出事。 AI 只負責放行，唔確定嘅落人手，永不自動拒絕。 同一段錄音順便標返你講粵／英／普。

假面

搖一搖變成一個真係用得嘅計數機，撳返一段特定數字先返到去。 對「同屋企人住、阿媽會攞我電話」嘅人，唔係花巧，係用唔用得落去嘅分別。

⚠️ 設計草圖。所有人物、貼文、對話全部虛構。個名仲未定。
